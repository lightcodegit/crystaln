# Changelog

Все заметные изменения проекта CrystalN документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [Unreleased]

### Добавлено

#### Новое в этой итерации
- **Мини-игра «CrystalN Jelly»** — скрытая кнопка-геймпад внизу настроек
  открывает желейный логотип с настоящей физикой: тянешь пальцем, отпускаешь
  — он летит по инерции, отскакивает от стен и дрожит как желе.
- **Обезличивать имена серверов** — переключатель в разделе «Приватность»:
  в списках вместо названий профилей показывается флаг страны (определяется
  по домену сервера) и номер, например «🇩🇪 #4».
- **Ссылка для тестирования подключения** и **таймаут проверки** —
  в разделе «Подключение» настраивается URL, который приложение активно
  проверяет через туннель при подключении (локальный SOCKS-probe), и время
  ожидания (3–60 сек) до объявления «сервер недоступен».
- **Плавнее стекло** — капля выбранного таба теперь растягивается как желе
  в движении и сплющивается на месте, иконки подскакивают пружиной;
  переходы между вкладками длиннее и мягче.

#### Windows — новая платформа
- **Полная поддержка Windows как отдельного десктоп-клиента** (`desktop`):
  сначала прокси-режим (SOCKS+HTTP), затем полный паритет с Android/Linux —
  TUN через tun2socks, WireGuard, AmneziaWG и OpenVPN на ядре xray.
- **Иконка в трее** — статус VPN прямо на панели задач, запуск/закрытие
  окна из трея.
- **Автозагрузка Windows** — переключатель в настройках, прописывается
  в реестре `HKCU\...\Run` (только для текущего пользователя).
- **Меню трея** — подключение/отключение выбранным профилем, быстрая
  сводка статуса, выход из приложения.
- **Уведомления Windows** — всплывающие уведомления при подключении и
  отключении VPN (тосты через Win32 API, без сторонних библиотек).
- **Статус-иконка в трее** — цвет и глиф меняются в зависимости от
  состояния туннеля (выключен / подключается / подключён).
- **Ручная проверка обновлений** — пункт меню трея и кнопка в настройках;
  диалог с ссылкой на свежий релиз, если есть новая версия.
- **MSI-установщик в релизах** — Windows-сборка публикуется как MSI
  (совместно с портативным ZIP).

#### Android — новые функции
- **Гироскоп фон — плавнее и сильнее** — амплитуда параллакса выросла
  (±90 → ±140 px), реакция на движение заметнее, а каждый слой кругов
  догоняет движение со своей пружиной — вместо дёрганого повторения
  сенсора получилось плавное «настигающее» движение.
- **Фон-жидкость — настоящая жидкость** — на Android 13+ шары перестают
  быть шарами: они рендерятся как поле метаболов (AGSL-шейдер) — шары
  тянутся друг к другу, срастаются «перешейками» и снова разделяются;
  движение растягивает каждую каплю вдоль её полёта (squash & stretch),
  цвета при слиянии смешиваются. Симуляция: наклон → стекание, встряска →
  всплеск, недодемпфированная пружина → колыхание поверхности. На более
  старых версиях — пружинные круги как раньше.
- **Гироскоп фон** — цветные круги на фоне двигаются под наклон телефона
  (параллакс): интеграция скорости вращения, экспоненциальное затухание
  к центру, ограничение ±90 px. Переключатель в Настройки → Оформление,
  по умолчанию выключен; работает на всех экранах через `CompositionLocal`.
- **AMOLED-режим** — чисто чёрный фон и поверхности в тёмной теме
  (#000000): пиксели OLED полностью выключаются, батарея экономится.
  Акценты палитры сохраняются, в светлой теме переключатель не действует.
- **Избранные профили** — звезда на карточке профиля закрепляет его
  наверх списка. Флаг сохраняется в JSON профиля и переживает обновление
  подписок.
- **Биометрический замок** — открытие приложения по отпечатку пальца
  (`androidx.biometric`): экран-замок, автозапуск системного промпта,
  переблокировка при каждом выходе из приложения. Без настроенного
  отпечатка в системе замок не блокирует.
- **Виджет 4×2 со списком профилей** — прокручиваемый список всех
  серверов прямо на рабочем столе, избранные сверху. Тап по серверу —
  подключение к нему, тап по текущему — отключение. Индикация: точка
  слева (зелёная — подключён, янтарная — подключение), фон виджета
  зеленеет при активном туннеле. Обновляется при изменении состояния VPN
  и при изменении списка профилей.
- **Весь главный экран листается целиком** — шапка, статус с кнопкой
  подключения, поиск и список профилей теперь один скролл: заголовок
  уезжает вверх вместе с контентом, вместо фиксированной шапки.
- **HTTPS-прокси** — новый тип профиля: HTTP CONNECT-прокси поверх TLS
  (ядро xray, outbound `http` + security `tls`). Импорт ссылок
  `https://user:pass@host:port#имя` создаёт HTTPS-профиль; в редакторе
  HTTPS доступен в списке протоколов (TLS включён по определению, секция
  security скрыта); шаринг ссылки — `https://…`. Поддержка также добавлена
  в desktop-версию (тот же протокол, редактор, парсер ссылок и диагностика).

### Добавлено
- **Профили — отдельная вкладка** — список серверов переехал со вкладки
  «Подключение» на собственную вкладку «Профили» (третья кнопка в
  стеклянной таб-панели). На вкладке подключения остался компактный вход
  в список профилей со счётчиком.
- **Группы профилей** — пользовательские группы: создаются в диалоге
  «Группы» на вкладке профилей, назначаются профилю в редакторе,
  фильтр-чипсы «Все / Избранное / группы / Без группы» с количеством;
  удаление группы не удаляет профили (снимает метку).
- **Полная проверка доступности всех профилей** — кнопка «проверить все»
  теперь показывает прогресс («Проверка… 5 из 30») и итог: сколько
  профилей отвечают и самый быстрый из них.
- **Проверка пинга любого сайта/IP** — новый раздел «Инструменты» в
  настройках: поле ввода (сайт, IP, можно с портом) и кнопка «Проверить»
  — TCP-подключение и время отклика, независимо от VPN и профилей.

### Исправлено
- **Отключение подписки не убирало её профили из списка** — переключатель
  подписки теперь скрывает её профили (и останавливает туннель, если он
  работал на одном из них); при повторном включении профили возвращаются
  обновлением.
- **Пинг не было видно на части профилей** — карточка профиля была
  перегружена: пинг, галочка выбора, звезда, «поделиться», изменить и
  удалить стояли в один ряд и вытесняли чип пинга. Карточка перестроена
  в два ряда: пинг и галочка справа сверху, действия (звезда/поделиться/
  изменить/удалить) — отдельным рядом, имя и адрес сервера получили всю
  ширину.
- **Виджет 1×3 «висел на "Подключении…"»** — переходы состояния
  (успешное подключение WireGuard/AmneziaWG, отключение, ошибки)
  публиковались без обновления виджета. Теперь обновление отправляется
  в каждой точке публикации состояния + страховочная подписка на
  изменения состояния.
- **MSI не собирался** — WiX-кодировка 1252 не умеет кириллицу
  в описании продукта (LGHT0311); описание переведено на ASCII.
- **В релизах попадал случайный ABI-split APK** — теперь публикуется
  universal debug-APK (ставится сразу), release-сборка подписывается
  через секреты.
- **Linux-сборка теряла `.deb`** — `targetFormats` перезаписывал список
  форматов; вызов теперь одним списком.
- **Проверка статуса бинарников на Windows** — `xray.exe` ищется через
  `Platform.binName` вместо хардкода имени без расширения.
- **Откат зависимостей, ломающих сборку**: compose-bom 2024.12.01
  (Compose 1.12 требует compileSdk 37 + AGP 9.1), core-ktx 1.13.1
  (1.19.1 требует AGP 9.1); haze-materials исключён из обновлений
  Dependabot до апгрейда тулчейна. Обновления core-ktx временно
  проигнорированы в Dependabot.

### Изменено
- **Рефакторинг десктопа** — большие файлы разбиты на модули:
  `App.kt` → `AppUtil.kt` + `dialogs/AppDialogs.kt`;
  `MainScreen` → `MainStatus` / `MainProfiles` / `ShareDialog`;
  `SettingsScreen` → вынесены палитра-пикер, строки настроек, диалог
  подписок; `TunnelManager` → ядро (~255 строк) + `TunnelBackends.kt`
  (бэкенды xray/WG/AWG/OpenVPN). Логика не менялась — чистое
  разделение ответственности.

## [0.1.0]

Первый публичный релиз.

- **Android** — мультипротокольный VPN-клиент: VMess, VLESS, Trojan,
  Shadowsocks, SOCKS5, HTTP (Xray), WireGuard и AmneziaWG
  (amneziawg-go), OpenVPN (openvpn 2.6). TUN и прокси-режимы,
  импорт из буфера/файла/QR/ссылки, подписки, избранное серверов,
  живая статистика трафика, диагностика, статус-виджет 1×3,
  Quick Settings плитка, защита от рекламы через geosite.
- **Linux** — десктоп-клиент с тем же ядром и полным паритетом
  протоколов.
- **CrystalN UI** — живые обои из цветных кругов, стеклянный
  «liquid glass» интерфейс, палитры, Material You (Android 12+),
  тёмная/светлая/системная темы, мастер первого запуска.
